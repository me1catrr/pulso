# PULSO

> ¿Puedo fiarme de este registro?

- Sitio web: <https://me1catrr.github.io/pulso/> (rama `gh-pages`, generada; no se edita a mano).

- Erratas y sugerencias: [incidencias](https://github.com/me1catrr/pulso/issues).

RESONANCIA, de analizarlos e interpretarlos.
